## Penjelasan Direktori & File

### 1. Direktori
* **`assets/`**
    Folder ini kemungkinan besar digunakan untuk menyimpan data mentah atau gambar input (citra asli) yang diperlukan untuk proses pengolahan citra digital pada saat UTS.
* **`outputs/`**
    Folder ini digunakan untuk menyimpan hasil keluaran (output) dari citra yang telah diproses oleh program, seperti gambar yang telah melalui proses *filtering*, *thresholding*, atau manipulasi piksel lainnya.
* **`reports/`**
    Folder ini diperkirakan berisi file laporan atau dokumentasi terkait hasil analisis dan penjelasan dari pengerjaan UTS, biasanya dalam format PDF atau dokumen lainnya.

### 2. File Kode (Jupyter Notebook)
* **`Soal_1.ipynb`**
    File ini berisi *source code* (kode sumber) dalam format Jupyter Notebook untuk menyelesaikan instruksi atau permasalahan dari Soal nomor 1.
* **`Soal_2.ipynb`**
    File ini berisi *source code* (kode sumber) dalam format Jupyter Notebook untuk menyelesaikan instruksi atau permasalahan dari Soal nomor 2.
